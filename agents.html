The CFO & AI Series

Agent Library

Five small agents that came out of the series so far — one per post that shipped one. Every one of them reads data and reports; none of them moves money or sends anything on its own.

5 agents 1 repository Sample data only Python, no dependencies beyond requirements.txt
01
From Post #2
Weekly CFO Report

Pulls financial data from a CSV, calculates the KPIs that matter — margin, burn, DSO, operating leverage — and has Gemini write the narrative around them. Delivered by email every Monday morning.

Read the post → See the walkthrough → View script
02
From Post #3
Invoice Agent

Reads open invoices, ranks the overdue ones by risk — amount times days late — and drafts a personalized reminder per client. It writes the drafts. It doesn't send them.

Read the post → See the walkthrough → View script
03
From Post #9
FX Monitoring Agent

Compares each open FX position's booked rate against a current one and flags anything that has drifted past a threshold you set — instead of finding out at month-end close.

Read the post → See the walkthrough → View script
04
From Post #10
Idle Cash Agent

Compares each account balance against its agreed buffer and estimates what the excess sitting above it could have earned, if it had been swept somewhere that pays interest.

Read the post → See the walkthrough → View script
05
From Post #11
Invoice Priority Agent

Reorders a payment queue by more than the printed due date — a critical-vendor flag can move an invoice ahead of an older one still waiting its turn.

Read the post → See the walkthrough → View script

All five are personal, non-commercial prototypes built on sample data — not connected to, and not built for, any company or client. Each one is an experiment in what a specific recurring check would actually need to compute, nothing more. One repository: github.com/LuliBobo/cfo-agents.
