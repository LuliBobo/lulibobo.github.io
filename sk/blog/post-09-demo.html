Doplnok k príspevku #9 — Séria CFO & AI

Agent, ktorý zachytí pohyb kurzu
skôr než to nájde uzávierka

Malý skript, ktorý načíta otvorené FX pozície a označí všetko, čo sa posunulo nad nastavený prah — skôr, než to nájde uzávierka na konci mesiaca.

📄 Boris Dračka · ⏱ 4 min čítania · 📦 Kód na GitHube

Toto je osobný, nekomerčný vedľajší projekt, ktorý som vytvoril, aby som sa učil — nie je to produkt ani služba a nie je napojený na žiadnu firmu, s ktorou spolupracujem.

6 Otvorených pozícií vo vzorových dátach
2 Označené nad prahom ±2 %
0 Potrebných API kľúčov či živých účtov
Slepé miesto
Prečo strata zostáva neviditeľná až do uzávierky

Post #9 vysvetlil, prečo FX strata zostáva neviditeľná až do uzávierky: faktúra sa zaúčtuje jedným kurzom, v jeden deň, a nič ten kurz znova neskontroluje, kým o niekoľko týždňov nepríde platba a niekto ju nezosúladí.

Tento skript je malý osobný experiment, ktorý som zložil, aby som zistil, čo by denná kontrola reálne musela počítať. Nič neobchoduje a nedotýka sa reálneho účtu — len načíta zoznam otvorených pozícií a spraví to jedno porovnanie, ktoré nikto nespustí až do uzávierky.

„Nič z toho nemusí byť komplikované. Len to musí bežať skôr, než sa kurz prestane hýbať — nie až potom."

Čo agent vidí
Každá otvorená pozícia oproti dnešnému kurzu
Načíta CSV s otvorenými pozíciami — faktúrami v cudzej mene, ktoré ešte neboli vyrovnané — a označí všetko nad nastavenou odchýlkou od zaúčtovania.

Ako to funguje
5 krokov. Jedno CSV. Žiadne živé napojenie.
Nič z toho nepotrebuje API kľúč ani reálny účet — je to výpočet, spustený na vzorových dátach.
1
📥
Načítanie otvorených pozícií
Načíta CSV: ID pozície, klient, menový pár, fakturovaná suma a kurz, ktorým bola zaúčtovaná.
Vstup CSV · bez API
2
🔁
Aplikovanie aktuálneho kurzu
Pre každú pozíciu porovná zaúčtovaný kurz s aktuálnym kurzom, ktorý pre daný pár zadáte.
Zadaný alebo manuálny kurz
3
🧮
Výpočet odchýlky
Vypočíta hodnotu v EUR pri oboch kurzoch a rozdiel — v eurách aj v percentách.
Hodnota v EUR = suma ÷ kurz
4
🚩
Označenie nad prahom
Všetko nad nastaveným percentom (predvolene 2 %) sa označí na druhé posúdenie.
Predvolený prah: ±2,0 %
5
🖨️
Výpis reportu
Vypíše zoradenú tabuľku plus zhrnutie v jednoduchom jazyku, čo je označené a prečo.
Výstup do terminálu · žiadny dashboard
Vyskúšajte si to sami
Potrebujete Python. To je všetko.
Žiadne API kľúče, žiadne napojenie na živý obchodný systém — len CSV s vlastnými otvorenými pozíciami.
1
Naklonujte repozitár
terminal 
# Naklonovanie repozitára
git clone https://github.com/LuliBobo/cfo-agents.git
cd cfo-agents
2
Pridajte svoje otvorené pozície
data/fx_positions.csv 
# position_id,client,currency_pair,amount_foreign,booked_rate,current_rate,invoice_date
FX-01,Iota Digital,EUR/USD,95000,1.0750,1.1100,2026-07-15
FX-02,Kappa Logistics,EUR/GBP,42000,0.8600,0.8550,2026-07-22
3
Spustite
terminal 
python fx_monitor_agent.py data/fx_positions.csv --threshold 2.0

📄 Zdroj dát

🐍 Výpočet

Python zo štandardnej knižnice — žiadne externé balíčky, žiadne API kľúče potrebné na spustenie.

python3 fx_monitor_agent.py

🎚️ Prah

Nastaviteľné percento rozhoduje, čo sa označí a čo je len bežný šum.

--threshold 2.0
