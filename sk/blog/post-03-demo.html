Agent, ktorý zháňa faktúry
aby ste to nemuseli robiť vy

30 % týždňa samostatného účtovníka ide na pohľadávky a fakturáciu. Tento agent monitoruje vaše faktúry po splatnosti, zoraďuje ich podľa rizika a píše pripomienkové e-maily — automaticky.

Problém
Kam skutočne ide 30 % týždňa

V príspevku #3 som vám ukázal rozpis času typického samostatného účtovníka v 50-člennej firme. Najväčšia jednotlivá kategória — 30 % týždňa — je fakturácia a pohľadávky.

To je 12 hodín každý týždeň strávených na: kontrole, ktoré faktúry sú po splatnosti, zisťovaní, koho treba naháňať, písaní pripomienkových e-mailov, opätovnom kontaktovaní, keď nedôjde odpoveď. Manuálne. Opakovane. Každý jeden týždeň.

Fakturácia a pohľadávky sú najväčším spotrebiteľom času. Sú tiež najlepšie automatizovateľné.

„Práca s najvyššou hodnotou — prognózovanie, scenárová analýza, proaktívne riadenie hotovosti — dostane 5 % času. Pretože zvyšných 95 % je už obsadených."

Toto je presne to, čo rieši Agent na faktúry po splatnosti. Nenahrádza účtovníka. Berie tých 30 %, ktoré nevyžadujú úsudok — a rieši to automaticky.

Ako to funguje
5 krokov. Každý pondelok. Automaticky.
Agent beží bez akéhokoľvek ľudského spustenia. Do 7:15 má účtovník kompletný report o faktúrach po splatnosti s návrhmi e-mailov pripravenými na kontrolu alebo odoslanie.
1
🔌
Stiahnutie dát o faktúrach
Prečíta váš súbor s faktúrami — CSV, Google Sheet alebo export z ERP. ID faktúry, meno klienta, suma, termín splatnosti, stav platby. Žiadna manuálna príprava.
CSV · Google Sheets · ERP export
2
🔍
Detekcia faktúr po splatnosti
Porovná termín splatnosti každej faktúry s dnešným dátumom. Zaradí každú faktúru po splatnosti do troch úrovní závažnosti: Kritická (60+ dní), Varovanie (30–60 dní), Sledovať (< 30 dní).
🔴 Kritické · 🟡 Varovanie · 🟢 Sledovať
3
📊
Prioritizácia podľa finančného rizika
Vypočíta skóre rizika pre každú faktúru: Suma × Dni po splatnosti. Faktúra na 31 000 €, ktorá má 81 dní omeškania, sa umiestni vyššie ako faktúra na 5 000 €, ktorá má 90 dní omeškania. Účtovník uvidí položky s najväčším dopadom ako prvé.
Skóre rizika = Suma × Dni po splatnosti
4
🤖
Generovanie personalizovaných pripomienok
Pre každú faktúru po splatnosti napíše Gemini AI prispôsobený pripomienkový e-mail. Tón sa prispôsobuje závažnosti — slušný pre prvé pripomienky, prísny a naliehavý pre faktúry po 60 dňoch. Meno klienta, číslo faktúry a suma sa dopĺňajú automaticky.
Gemini API · Tón podľa závažnosti · Personalizované pre klienta
5
📬
Doručenie súhrnu účtovníkovi
Odošle jeden e-mail účtovníkovi s kompletným reportom o faktúrach po splatnosti: súčty, rozpis podľa závažnosti a všetky návrhy pripomienkových e-mailov pripravené na skopírovanie, kontrolu a odoslanie. Žiadne naháňanie. Žiadne manuálne písanie.
Doručenie e-mailom · Návrhy pripomienok súčasťou
Výsledok: Čo kedysi trvalo 3 hodiny, teraz zaberie 3 minúty na kontrolu a akciu.

Ako to nastaviť za 30 minút
Potrebujete Python, bezplatný Gemini API kľúč a tabuľku s vašimi faktúrami. To je všetko.
1
Naklonujte repozitár a nainštalujte závislosti
terminal 
# Naklonujte repozitár
git clone https://github.com/LuliBobo/cfo-agents.git
cd cfo-agents

# Nainštalujte dva potrebné balíky
pip install -r requirements.txt
2
Pridajte svoje dáta o faktúrach
data/invoices.csv 
# Upravte tento súbor svojimi skutočnými faktúrami
invoice_id,client,amount_eur,due_date,contact_email,status
INV-001,Acme Corp,12500,2026-04-01,finance@acmecorp.com,unpaid
INV-002,Beta GmbH,4800,2026-04-20,ap@betagmbh.de,unpaid
INV-003,Your Client,31000,2026-03-15,billing@client.com,unpaid
3
Nastavte API kľúč a e-mail
.env 
# Skopírujte šablónu a doplňte svoje hodnoty
cp .env.example .env

# Obsah súboru .env:
GEMINI_API_KEY=your_key_from_aistudio.google.com
SENDER_EMAIL=your@gmail.com
SENDER_PASSWORD=your_gmail_app_password
RECIPIENT_EMAIL=accountant@yourcompany.com
COMPANY_NAME=Your Company Name
4
Spustite agenta a pozrite si výstup
terminal 
# Najprv ho spustite manuálne na test
python invoice_agent.py
